# Agentic Music

Un cours d’Internet Music pour musiciennes et musiciens ayant peu d’expérience technique, sur Windows et macOS. **Chaque séance produit un objet musical audible, partageable et transformable.**

Le fil conducteur : une intention dans Obsidian → un petit contrat confié à un agent → des fichiers lisibles dans VS Code → une écoute et une décision humaine → une version Git → une URL sur GitHub Pages, éventuellement Vercel.

Commencer par [[agentic music MOC]], puis [[Programme - 10 séances]] et [[classe-01-machines-qui-ecoutent]]. L’installation se prépare avec [[Installation - Windows et macOS]].

Deux ouvrages structurent l’atelier : Maya Ackerman, *Creative Machines: AI, Art & Us* (2026), et Emily K. Johnson / Anastasia Salter, *Critical Making in the Age of AI* (2025). Voir [[Lectures - concepts et exercices]] pour les pages et les adaptations.

La séance 1 est rédigée et accompagnée de deux applications. Les séances 2–10 sont planifiées ; leurs présentations complètes restent à rédiger. Les dates seront fixées avec l’enseignant.
