# Initiation — Mac et macOS / Getting started with Mac and macOS

Aide-mémoire de niveau débutant. Première colonne en français, deuxième en anglais ; les raccourcis sont surlignés.
Beginner cheat sheet. French first, English second; shortcuts are highlighted.

Note : « OS X » est l'ancien nom du système. Depuis 2016 il s'appelle macOS ; la version actuelle est macOS 26 Tahoe. Les noms d'éléments ci-dessous sont ceux de macOS en français.

| Français | English | Symbole |

| Option (alt) | Option (alt) | ==⌥== |

Règle d'or : sur Mac, ⌘ remplace presque toujours le Ctrl de Windows (copier = ⌘ C, pas Ctrl C).
Rule of thumb: on Mac, ⌘ replaces Windows Ctrl in almost every case.

## 3. Fenêtres et applications — Windows and apps

Différence clé avec Windows : fermer une fenêtre (⌘ W) ne quitte pas l'application ; il faut ⌘ Q. Un point sous l'icône du Dock indique une app encore ouverte.
Key difference from Windows: closing a window (⌘ W) does not quit the app; use ⌘ Q. A dot under a Dock icon means the app is still running.

## 4. Spotlight — Spotlight

Spotlight est la recherche globale : apps, fichiers, calculs, conversions, définitions. C'est le moyen le plus rapide d'ouvrir n'importe quelle application.
Spotlight is system-wide search: apps, files, calculations, conversions, definitions. It is the fastest way to open any app.

| Français | English | Raccourci |
| --- | --- | --- |
| Ouvrir Spotlight | Open Spotlight | ==⌘ + Espace== |
| Ouvrir le premier résultat | Open top result | ==↩== |
| Afficher le fichier dans le Finder | Reveal file in Finder | ==⌘ + ↩== |
| Catégorie Applications | Applications category | ==⌘ + 1== (dans Spotlight) |
| Catégorie Fichiers | Files category | ==⌘ + 2== |
| Catégorie Actions (Raccourcis) | Actions category (Shortcuts) | ==⌘ + 3== |
| Historique du presse-papiers | Clipboard history | ==⌘ + 4== (à activer dans Réglages Système → Spotlight) |
| Recherches précédentes | Previous searches | ==↑== |
| Fermer Spotlight | Close Spotlight | ==⎋== |

Exemples à taper : `Terminal`, `Moniteur d'activité`, `12*7`, `440 Hz en ms` (calcul), `100 CHF en EUR`.
Examples to type: `Terminal`, `Activity Monitor`, `12*7`, `100 CHF to EUR`.

Utilities live in Applications → Utilities (==⇧ + ⌘ + U==) or via Spotlight.

| Console | Console | Lire les messages d'erreur du système et des apps |
| Capture d'écran | Screenshot | Même outil que ==⇧ + ⌘ + 5== |
| Terminal | Terminal | Ligne de commande (sections 8–9) |
| Colorimètre numérique | Digital Color Meter | Lire la couleur RVB d'un pixel à l'écran |
| Éditeur de script | Script Editor | AppleScript / JavaScript pour automatiser des apps |
| Mots de passe | Passwords | Mots de passe et codes enregistrés (remplace en grande partie Trousseau d'accès) |
