# Concept — API

**FR :** Interface définie qui permet à un programme d’utiliser les fonctions d’un autre composant ou service.

**EN:** A defined interface that lets a program use functions from another component or service.

## Dans mon instrument

Web Audio API fournit les oscillateurs, les gains et la lecture de buffers du navigateur.

## Ce que ce n’est pas

Une API n’est pas nécessairement un service web payant ou distant.

## Vérification de 30 secondes

Montrer la fonction qui crée un oscillateur dans Écho.
