# Concept — Paramètre

**FR :** Valeur qui règle un fonctionnement ; dans un modèle appris, certains paramètres sont ajustés à partir d’exemples.

**EN:** A value that controls a process; in a learned model, some parameters are fitted from examples.

## Dans mon instrument

La fréquence 220 Hz est un réglage de synthèse ; le centroïde de Nuage est calculé à partir des exemples.

## Ce que ce n’est pas

Un modèle « 300M » compte des paramètres appris ; ce n’est pas un nombre de notes ou de boutons.

## Vérification de 30 secondes

Montrer un réglage humain et une valeur apprise dans les exports.
