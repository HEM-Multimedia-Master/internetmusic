# Concept — Dépôt

**FR :** Ensemble de fichiers d’un projet et de leur historique de versions, local ou partagé.

**EN:** A collection of project files and their version history, stored locally or shared.

## Dans mon instrument

Le dépôt étudiant contient index.html et les deux instruments.

## Ce que ce n’est pas

Un dépôt GitHub n’est pas automatiquement un site publié ni une machine GPU.

## Vérification de 30 secondes

Retrouver le changement d’une valeur dans une différence Git.
