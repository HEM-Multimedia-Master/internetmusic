# Concept — Circuit Cloud (`[[github-dev]]`, `[[copilot]]`, `[[colab]]`, `[[github-pages]]`, `[[vercel]]`)

**FR :** Chaine de création 100 % dans le navigateur évitant toute installation locale : `[[colab]]` pour les notebooks Python sur GPU, `[[github-dev]]` (touche `.` sur GitHub) + `[[copilot]]` pour coder en HTML/JS, et `[[github-pages]]` ou `[[vercel]]` pour publier une URL HTTPS jouable.

**EN:** 100% browser-based creative workflow requiring zero local setup: `[[colab]]` for GPU Python notebooks, `[[github-dev]]` (press `.` on GitHub) + `[[copilot]]` for HTML/JS coding, and `[[github-pages]]` or `[[vercel]]` for live HTTPS deployment.

## Dans notre cours à la HEM

1. **GitHub Education (`@hesge.ch`)** : donne accès gratuitement à **GitHub Copilot Pro** et **GitHub Codespaces** aux étudiants et enseignants vérifiés (et **Copilot Free** immédiatement sans attente).
2. **`[[github-dev]]` (`https://github.dev/...`)** : en pressant la touche `.` sur n'importe quel dépôt GitHub, VS Code s'ouvre dans le navigateur avec le chat d'agent Copilot et le commit en un clic.
3. **Google `[[colab]]`** : exécute les scripts Python (Hugging Face, Whisper, CLAP, MusicGen) sur les serveurs Google sans installer Python ni télécharger des gigaoctets sur l'ordinateur personnel.

## Ce que ce n’est pas

`github.dev` est un éditeur dans le navigateur ; pour que le microphone et l'instrument soient jouables sur téléphone, on publie le dépôt sur `[[github-pages]]` ou `[[vercel]]` afin d'obtenir une URL `https://`.

## Vérification de 30 secondes

Ouvrir son dépôt sur `github.com`, appuyer sur la touche `.` du clavier et vérifier l'ouverture de l'éditeur VS Code Web.
