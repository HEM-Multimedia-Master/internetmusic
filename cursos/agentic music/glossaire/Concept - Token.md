# Concept — Token

**FR :** Unité de texte utilisée par un modèle, souvent un morceau de mot, une ponctuation ou un espace.

**EN:** A unit of text used by a model, often a word fragment, punctuation, or whitespace.

## Dans mon instrument

Le prompt, les fichiers joints et la réponse consomment un budget de tokens ; leur découpage dépend du tokenizer.

## Ce que ce n’est pas

Un token n’est pas nécessairement un mot ; un token d’accès GitHub est un identifiant secret, différent.
