A cloud workflow is a creation chain that runs entirely in the browser, with no local installation. Colab runs Python notebooks (Hugging Face, Whisper, CLAP, MusicGen) on Google GPUs; github.dev, opened by pressing `.` on any GitHub repository, provides VS Code in the browser with Copilot agent chat and one-click commits; GitHub Pages or Vercel then publish the repository at an HTTPS address. github.dev is an editor, not a host: for the microphone and the instrument to work on a phone, the repository must be published to obtain an `https://` URL. Through GitHub Education, verified students and teachers get GitHub Copilot Pro and Codespaces at no cost.
