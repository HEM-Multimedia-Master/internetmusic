An agent is a system that pursues a goal by looping through context, decision, and action: it reads a file, proposes an edit, then uses a tool to carry it out. What distinguishes it from a simple control is the loop and the capacity to act on its environment; a slider tied to a volume parameter does not become an autonomous agent by being automated. The practical question is which actions the agent performs and which decisions remain with the human.

Un agent est un système qui poursuit un objectif en bouclant sur le contexte, la décision et l'action : il lit un fichier, propose une édition, puis utilise un outil pour la réaliser. Ce qui le distingue d'une simple commande est la boucle et la capacité d'agir sur son environnement ; un curseur lié à un paramètre de volume ne devient pas un agent autonome du seul fait d'être automatisé. La question pratique est de savoir quelles actions l'agent réalise et quelles décisions restent à l'humain.
