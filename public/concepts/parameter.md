A parameter is a value that sets how a process runs. A synthesis frequency of 220 Hz is a setting chosen by a person; the centroid in Nuage is a value computed from examples. When a model is described as "300M", the figure counts learned parameters, not notes or knobs.

<!--lang:fr-->
Un paramètre est une valeur qui règle le fonctionnement d'un processus. Une fréquence de synthèse de 220 Hz est un réglage choisi par une personne ; le centroïde de Nuage est une valeur calculée à partir d'exemples. Lorsqu'un modèle est qualifié de « 300M », ce chiffre compte des paramètres appris, et non des notes ou des boutons.
