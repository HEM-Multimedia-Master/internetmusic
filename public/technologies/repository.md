A repository is the set of files of a project together with its version history, stored locally or shared. In the course, the student repository holds `index.html` and the two instruments, and a Git diff shows when a value changed. A GitHub repository is not automatically a published website, nor a GPU machine.

<!--lang:fr-->
Un dépôt (repository) est l'ensemble des fichiers d'un projet et de leur historique de versions, local ou partagé. Dans le cours, le dépôt étudiant contient `index.html` et les deux instruments, et une différence Git montre à quel moment une valeur a changé. Un dépôt GitHub n'est pas automatiquement un site publié, ni une machine GPU.
